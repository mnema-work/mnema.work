# Where the logos of the hosts come from

The files in this folder are the vendors' own, as published, untouched: not recoloured, not resized in the file, not
redrawn, and never a third party's redraw of a logo. Each is fetched from the vendor's brand page, its own repository or
its own site. A host is shown by its logo on the home page only for a file listed here, and always beside its name in
text; a host that is not in the table is shown by its name alone. Where a vendor's page says that approval is needed or
that a third party may not use its logo this way, the section of the host quotes it: the logo is shown anyway, and the
page's footer says that the logos identify the hosts mnema works with and imply no endorsement.

## Claude Code

The rule, from https://www.anthropic.com/legal/trademark-guidelines: "You may only use our trademarks as specifically permitted by us and only in materials we approve beforehand."

What this site does: shows the icon claude.com serves, unmodified, beside the name "Claude Code" in text. This site has no approval from Anthropic on file.

## VS Code

The rule, from https://code.visualstudio.com/brand: "Not OK Using the icon to identify or promote your own product, service, application, VS Code extension, blog, podcast, newsletter, video, channel, etc." and "Not OK Using our icons to associate your offerings with Microsoft or its brands in any way." The same page allows: "OK Using the icon in a documentation or tutorial (in both text and video formats), blog post, news article about Visual Studio Code."

What this site does: shows the stable icon of the vendor's archive, unmodified, beside the name "VS Code" in text, to say which host a thing works in. The page says the icon may not identify or promote a product of ours; this site has no approval from Microsoft on file.

## Copilot CLI

The rule, from https://brand.github.com/foundations/logo: "Use a permitted GitHub logo to inform others that your project integrates with GitHub." and "Use the permitted GitHub logos less prominently than your own company or product name or logo." and "Do not modify the permitted GitHub logos, including changing the color, dimensions, or combining with other words or design elements." and "Do not use GitHub trademarks, logos, or artwork without GitHub's prior written permission." The same page says that, beginning in 2025, GitHub Copilot no longer has a standalone logo that heros the Copilot icon, so the logo shown is GitHub's.

What this site does: shows the Invertocat in white (the page is dark), unmodified, at a size smaller than the name of this product, linked to https://github.com. The words "Copilot CLI" are the name of the host, in a separate element beside the mark: the two are not drawn as one lockup. This site has no written permission from GitHub on file.

Not Cursor AI or Cursor Code." The page states no rule of use by third parties.

## OpenCode

The rule, from https://opencode.ai/brand (Integrations): "Plugins, providers and tools that work with OpenCode, and projects built with it, can say so. Use a badge or a partner lockup, and name your project so it is clear that it is yours." and "Put a badge in your README, docs or website and link it to opencode.ai. Pick the light or dark file for your background (the HTML switches by itself), and do not change the colors or the text." The same page says: "OpenCode and the OpenCode logo are trademarks of Anomaly. Do not use them to suggest that Anomaly endorses or sponsors you, in your product or company name, or on merchandise without permission."

What this site does: shows the logo file of the brand page (opencode-logo-transparent-dark.svg, for a dark page), unmodified, at the same height as every other mark, with no width set so it is not stretched or squashed, linked to https://opencode.ai, beside the name of the host in text. It is the logo, not the "Works with" badge.
